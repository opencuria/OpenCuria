# Workspace tools sheet

`WorkspaceToolsSheet` presents Git, Desktop, Terminal and Files of the chat's workspace.
`MainScreen` opens it from the chat header's branch button or the transcript's pull-up
(`ChatMessages.onPullUpAtEnd`).

The Git repository selection persists per server, organization and workspace
through app restarts using the native SecureStore adapter.

Each section is a panel in `panels.ts` receiving `WorkspaceToolProps`
(`types.ts`): client, workspace, `active` (visible section), media cache, bottom
inset and `onInsertIntoChat`. Panels mount on first use and stay alive while the
sheet is open. Viewers open in `ToolDetailSheet` (native bar: close, title,
subtitle, overflow menu).

| Folder | Contents |
| --- | --- |
| `git/` | `createGitController` (binds the shared `@opencuria/chat-core/gitController` to `client.git`, toasts and the saved repo selection), `GitPanel`, VS Code's action button (`gitActionButton.ts`), per-row graph drawing (`graphRows.ts`), diff (`lineDiff.ts`, `GitDiffSheet`), commit and branch sheets. Rules and wire types come from `@opencuria/chat-core/git*`, REST from `client.git`. |
| `desktop/` | `DesktopPanel` (status bar, menu, layout, keyboard and the viewer page lifecycle of the webapp's `DesktopSurface`), `useDesktopViewer` (`desktopSession.ts`: the shared `@opencuria/chat-core/desktopViewer` coordinator bound to `client.desktop`, realtime and app state), `DesktopScreen` (WebView, native zoom/pan and cursor), `DesktopTrackpad`, touch recognition for both (`desktopGestures.ts`: pure state machines run as worklets), pointer math (`pointerMath.ts`, worklets), keys (`desktopKeys.ts`) and the KasmVNC page bridge (`viewerBridge.ts`). The key row above the keyboard is the shared `KeyAccessoryBar`. |
| `terminal/` | `TerminalSession` (REST start, Socket.IO I/O, retained output, reconnect), the libghostty surface (`mobile/modules/opencuria-terminal`) and `TerminalPanel` (key row, menu). Release sessions with `releaseTerminalSessions(client)`. |
| `files/` | Lazy tree and search (`useFileTreeEntries`, `FileTreeBrowser`), `FileViewerSheet`, `SourceView` with the native highlighter (`mobile/modules/opencuria-highlights`), file icons generated by `mobile/scripts/generate-file-icons.mjs`. |

Terminal, highlighter and file browser are adapted from t3code (MIT); see
`THIRD_PARTY_NOTICES.md`.
